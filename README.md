## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Kit Library** | Organize Battery 4 kits by genre, BPM and production style |
| **Sample Notes** | Document sample layering and velocity configuration per kit |
| **Cell Config** | Track cell group and output routing settings per kit design |
| **Genre Curation** | Build curated kit lists for specific genre production projects |
